# steel-manufacturing-finance-tools
**Finance Executive | Aryan Ispat Limited | Jharsuguda**

Excel-based MIS tools built from 2 years of DRI finance experience.

## Tools Included

### 1. Sponge Iron (DRI) MIS Dashboard
350 TPD rotary kiln operations — 6-sheet integrated model
- Daily raw data entry: pellet, coal, dolomite MT; A/B grade production
- KPI tracking: coal spec consumption, yield ratio, A grade %, metallisation
- Cost Impact: RM cost/MT, SUMPRODUCT-based monthly aggregation
- Selling Price Register: section-wise dispatch, net realisation
- Monthly P&L: Revenue to PAT with 9 management ratios
